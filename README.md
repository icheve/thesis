Тема дипломной работы - Разработка нагруженного в режиме близкого к реальному времени конвейера данных поставки платёжной информации, с сохранением истории платежей (Development of an NRT (near real-time) data pipeline for the supply of payment information, while maintaining the payment history)

Студент - Ичёв Евгений Вадимович

Научный руководитель - Заигрин Вадим Валерьевич

План работ:

1. Постановка задачи и требований

* цель, границы, ключевые сценарии
* требования по задержке, нагрузке, надёжности, хранению истории

2. Обзор и выбор подхода

* обзор архитектур и инструментов
* выбор целевого решения и обоснование

3. Проектирование архитектуры

* схема потоков данных
* контракты данных
* общие принципы качества, мониторинга и безопасности

4. Проектирование хранения истории платежей

* модель истории
* ключи, правила дедупликации/идемпотентности, период хранения

5. Подготовка данных и тестовых сценариев

* генерация/обезличивание данных
* набор кейсов для проверки корректности и устойчивости

6. Реализация конвейера

* ingestion (приём событий)
* обработка/трансформации
* загрузка в хранилище с сохранением истории

7. Проверка качества и наблюдаемость

* базовые проверки качества данных
* метрики/логи/алерты, обработка ошибок

8. Тестирование и нагрузка
   
* нагрузочное тестирование, анализ ограничений, доработки

9. Итоговое оформление

* документация и инструкции развертывания
* описание результатов, замеров и выводы для диплома
